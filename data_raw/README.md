# Raw Data

The full raw-data cache is not included in this GitHub-ready package.

Reasons:

- the local raw cache is approximately 1 GB,
- several raw files exceed practical GitHub file-size limits,
- all sources are public and should be retrieved from official providers,
- derived aggregate outputs needed to verify the analysis are included.

Use `data_raw/_metadata/sources_inventory.csv` to identify the raw public
sources used in the analysis.
